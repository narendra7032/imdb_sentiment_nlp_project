# 🎬 IMDB Movie Review Sentiment Analysis — End-to-End NLP Project

A complete NLP pipeline on the IMDB 50k Movie Reviews dataset, from raw text to a
deployed Streamlit app.

## Project structure

```
project/
├── data/
│   └── IMDB Dataset.csv        # 50,000 labeled movie reviews (25k pos / 25k neg)
├── models/                     # created by train.py
│   ├── sentiment_model.joblib
│   ├── tfidf_vectorizer.joblib
│   ├── confusion_matrix.png
│   ├── roc_curve.png
│   └── model_info.txt
├── preprocessing.py             # shared text-cleaning function
├── train.py                     # trains & evaluates models, saves the best one
├── app.py                       # Streamlit app (prediction + EDA + model info)
├── requirements.txt
└── README.md
```

## 1. Setup

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## 2. Train the model

```bash
python train.py
```

This will:
- Load and de-duplicate the 50k reviews
- Clean text (strip HTML tags, lowercase, remove punctuation/numbers)
- Split 80/20 train/test (stratified)
- Vectorize with TF-IDF (unigrams + bigrams, 40k features)
- Train and compare **Logistic Regression**, **Linear SVM**, and **Multinomial Naive Bayes**
- Save the best model (by F1 score) + vectorizer + confusion matrix + ROC curve to `models/`

Typical result: **~90% accuracy / ~0.90 F1** with Logistic Regression.

## 3. Run the app locally

```bash
streamlit run app.py
```

Opens at `http://localhost:8501` with three tabs:
- **Predict** — type/paste a review, get an instant sentiment + confidence score
- **Explore Dataset** — class balance chart + sample reviews
- **About the Model** — metrics, pipeline summary, confusion matrix, ROC curve

## 4. Deploy to Streamlit Community Cloud (free)

1. Push this project (including the `models/` folder generated by `train.py`) to a public GitHub repo.
   - Note: `IMDB Dataset.csv` is ~66MB — GitHub allows files up to 100MB, so it's fine to commit directly.
2. Go to [share.streamlit.io](https://share.streamlit.io) and sign in with GitHub.
3. Click **New app**, select your repo/branch, and set the main file to `app.py`.
4. Click **Deploy**. Streamlit Cloud will install `requirements.txt` and launch the app automatically.

Your app will be live at a URL like:
`https://<your-app-name>.streamlit.app`

### Notes for deployment
- Make sure `models/*.joblib` are committed — the app loads them directly rather than retraining on startup.
- If your repo has size limits, you can instead have `app.py` train on first run, but pre-saved artifacts load instantly and are recommended.

## Possible extensions
- Swap TF-IDF + Logistic Regression for a fine-tuned DistilBERT/BERT model for higher accuracy
- Add batch prediction via CSV upload in the app
- Add word-cloud or top-feature (most predictive words) visualizations
- Track experiments with MLflow
